# Graft to Claude Code Compilation Target

This document defines how each element of the Graft language is transformed into a Claude Code harness structure.

## Overview

```
.gft Source ──→ Graft Compiler ──→ Claude Code Harness
                                   │
                                   ├── .claude/CLAUDE.md
                                   ├── .claude/agents/
                                   ├── .claude/skills/
                                   ├── .claude/hooks/
                                   ├── .claude/settings.json
                                   └── .graft/ (runtime data)
```

## 1. Node to Agent Definition

### Input (.gft)
```graft
node Analyzer {
  model: sonnet
  reads: [ProjectSpec, CodebaseMap]
  produces: AnalysisResult {
    schema {
      issues: List<Issue>
      risk_score: Float(0..1)
    }
  }
  tools: [file_read, ast_parse]
  budget { input: 4000, output: 2000 }
  on_failure: retry(max: 2)
}
```

### Output (.claude/agents/analyzer.md)
```markdown
---
name: analyzer
description: Agent that analyzes codebase structure and patterns.
model: claude-sonnet-4-20250514
tools:
  - Read
  - Bash
  - Skill
---

# Analyzer Agent

## Startup Protocol
1. Load the /inject-context:project-spec skill to acquire project context
2. Load the /inject-context:codebase-map skill to acquire codebase structure
3. Begin analysis based on the above contexts

## Output Contract
On completion, output a result conforming to the JSON schema below:
\```json
{
  "issues": [
    {"file": "string", "line": 0, "severity": "low|medium|high|critical", "description": "string"}
  ],
  "risk_score": 0.0
}
\```

## Token Discipline
- Do not read entire files. Extract only function signatures, imports, and key logic.
- Output must stay within 2000 tokens.
- Do not include unnecessary explanations or reasoning traces in output.

## Completion
On analysis completion, save JSON result to .graft/session/node_outputs/analyzer.json.
Output the ===NODE_COMPLETE:analyzer=== marker.

## Failure
Retry up to 2 times. On 3rd failure, output the ===NODE_FAILED:analyzer=== marker.
```

## 2. Context to Skill (Injection Module)

### Input (.gft)
```graft
context CodebaseMap : Indexed {
  source: knowledge_graph("product_domain")
  retrieval: graph_traverse(start: "current_feature", hops: 2)
  max_tokens: 3000
}
```

### Output (.claude/skills/inject-context/codebase-map/SKILL.md)
```markdown
---
name: inject-context:codebase-map
description: >
  Injects codebase structure context into the current agent.
  Use when information about module structure, dependencies, and conventions is needed.
---

# Codebase Map Context Injection

## Procedure
1. Read the .graft/knowledge/product_domain.json file
2. Extract entities related to the current task via graph_traverse
   - Start point: entity related to the current feature
   - Traverse up to 2 hops
3. Compress extracted information into the format below

## Output Format (max 3000 tokens)
```
[CTX:CODEBASE_MAP]
modules:
  - name: <module> | files: <count> | pattern: <arch_pattern>
    deps: [<key_dependencies>]
    conventions: [<coding_conventions>]
  ...
relations:
  - <module_a> -> <module_b>: <relation_type>
  ...
[/CTX:CODEBASE_MAP]
```

## Token Control
- Do not list all files
- Provide module-level summaries only
- If exceeding 3000 tokens, remove items with the lowest relevance scores first
- Show only names for modules unrelated to the current task
```

## 3. Edge Transform to Hook Script

### Input (.gft)
```graft
edge Analyzer -> Reviewer {
  transform {
    select: issues where severity >= "medium"
    drop: reasoning_trace
    format: compact
  }
}
```

### Output (.claude/hooks/transform-analyzer-to-reviewer.sh)
```bash
#!/bin/bash
# Auto-generated by Graft Compiler
# Edge: Analyzer -> Reviewer
# Transform: select severity>=medium, drop reasoning_trace, format compact

set -euo pipefail

INPUT_FILE=".graft/session/node_outputs/analyzer.json"
OUTPUT_FILE=".graft/session/node_outputs/analyzer_to_reviewer.json"
TOKEN_LOG=".graft/token_log.txt"

if [ ! -f "$INPUT_FILE" ]; then
  echo "[Graft] ERROR: Analyzer output not found at $INPUT_FILE" >&2
  exit 1
fi

# Transform: select + drop + compact
jq '{
  issues: [.issues[] | select(.severity == "medium" or .severity == "high" or .severity == "critical")],
  risk_score: .risk_score
}' "$INPUT_FILE" > "$OUTPUT_FILE"

# Token accounting
ORIGINAL=$(wc -c < "$INPUT_FILE")
TRANSFORMED=$(wc -c < "$OUTPUT_FILE")
REDUCTION=$(( (ORIGINAL - TRANSFORMED) * 100 / ORIGINAL ))
TIMESTAMP=$(date '+%Y-%m-%d %H:%M:%S')

echo "[$TIMESTAMP] Edge Analyzer->Reviewer | ${ORIGINAL}B → ${TRANSFORMED}B (${REDUCTION}% reduction)" >> "$TOKEN_LOG"
```

### Hook Registration (.claude/settings.json)
```json
{
  "hooks": {
    "PostToolUse": [
      {
        "matcher": "Write(.graft/session/node_outputs/analyzer.json)",
        "command": ".claude/hooks/transform-analyzer-to-reviewer.sh"
      }
    ]
  }
}
```

## 4. Graph Flow to CLAUDE.md Orchestration

### Input (.gft)
```graft
graph CodeReviewPipeline {
  input: PullRequest
  output: ReviewDecision
  budget: 25000 tokens

  flow {
    Analyzer
    -> parallel {
      SecurityReviewer
      PerformanceReviewer
    }
    -> Aggregator
    -> done
  }
  
  shared_context: [ProjectSpec]
}
```

### Output (CLAUDE.md orchestration section)
```markdown
# Graft Orchestration: CodeReviewPipeline

> This project is an agent team orchestration generated by the Graft Compiler.
> Do not modify directly. To make changes, edit the .gft source and recompile.

## Execution Plan

Total token budget: 25,000
Shared context: ProjectSpec (accessible by all agents)

### Phase 1: Analysis [sequential]
- Agent: analyzer
- Expected tokens: input ~5,000 / output ~2,000
- Completion condition: verify ===NODE_COMPLETE:analyzer===
- Result stored at: .graft/session/node_outputs/analyzer.json

### Phase 2: Review [parallel] 
Spawn agent team:
- Agent: security-reviewer (expected: ~4,000 tokens)
- Agent: performance-reviewer (expected: ~4,000 tokens)

Important: Each agent receives the **transformed output**, not the full output from Analyzer.
(Edge transform filters to severity >= medium only)
Input file: .graft/session/node_outputs/analyzer_to_*.json

### Phase 3: Aggregation [sequential]
- Agent: aggregator
- Input: merged outputs from all Phase 2 agents
- Expected tokens: input ~3,000 / output ~1,000

## Token Budget Tracking
Check .graft/token_log.txt after each Phase.
- At 80% budget consumed: switch remaining agents to compact mode
- At 90% budget consumed: run only essential agents, skip the rest

## Failure Recovery
- Agent failure: retry/fallback/abort per on_failure policy
- Token overrun: switch to compact mode and continue
- Total failure: intermediate results preserved in .graft/session/ for manual recovery

## Data Flow Diagram
```
PullRequest
    │
    ▼
[Analyzer] ─── .graft/session/node_outputs/analyzer.json
    │
    ├── transform(select severity>=medium) ──→ [SecurityReviewer]
    │                                              │
    └── transform(select severity>=medium) ──→ [PerformanceReviewer]
                                                   │
                                    merge ◄────────┘
                                      │
                                      ▼
                                [Aggregator]
                                      │
                                      ▼
                              ReviewDecision
```
```

## 7. CLI Commands

```bash
# Compile: .gft to .claude/ structure
graft compile <source.gft> [--target claude-code] [--output-dir .]

# Run: execute compiled structure with Claude Code
graft run <source.gft> --input <input.json>

# Analyze only: static token flow analysis (no execution)
graft analyze <source.gft>

# Check: syntax + type + scope checking (no compilation)
graft check <source.gft>

# Token report: token usage report from the last run
graft report [--format json|text|chart]

# Initialize: create a new Graft project
graft init [--template basic|full]
```
