# Graft → Claude Code Compilation Target

이 문서는 Graft 언어의 각 요소가 Claude Code 하네스 구조로 어떻게 변환되는지를 정의합니다.

## Overview

```
.gft Source ──→ Graft Compiler ──→ Claude Code Harness
                                   │
                                   ├── .claude/CLAUDE.md
                                   ├── .claude/agents/
                                   ├── .claude/skills/
                                   ├── .claude/hooks/
                                   ├── .claude/settings.json
                                   └── .graft/ (runtime data)
```

## 1. Node → Agent Definition

### Input (.gft)
```graft
node Analyzer {
  model: sonnet
  reads: [ProjectSpec, CodebaseMap]
  produces: AnalysisResult {
    schema {
      issues: List<Issue>
      risk_score: Float(0..1)
    }
  }
  tools: [file_read, ast_parse]
  budget { input: 4000, output: 2000 }
  on_failure: retry(max: 2)
}
```

### Output (.claude/agents/analyzer.md)
```markdown
---
name: analyzer
description: 코드베이스 구조와 패턴을 분석하는 에이전트.
model: claude-sonnet-4-20250514
tools:
  - Read
  - Bash
  - Skill
---

# Analyzer Agent

## Startup Protocol
1. /inject-context:project-spec 스킬을 로드하여 프로젝트 컨텍스트 확보
2. /inject-context:codebase-map 스킬을 로드하여 코드베이스 구조 확보
3. 위 컨텍스트를 기반으로 분석 시작

## Output Contract
분석 완료 시 반드시 아래 JSON 스키마를 따르는 결과를 출력:
\```json
{
  "issues": [
    {"file": "string", "line": 0, "severity": "low|medium|high|critical", "description": "string"}
  ],
  "risk_score": 0.0
}
\```

## Token Discipline
- 파일 읽기 시 전체를 읽지 않음. 함수 시그니처, import, 핵심 로직만 발췌.
- 출력은 반드시 2000 토큰 이내.
- 불필요한 설명이나 추론 과정을 출력에 포함하지 않음.

## Completion
분석 완료 시 JSON 결과를 .graft/session/node_outputs/analyzer.json에 저장.
===NODE_COMPLETE:analyzer=== 마커를 출력.

## Failure
2회까지 재시도. 3회 실패 시 ===NODE_FAILED:analyzer=== 마커 출력.
```

### Output (.claude/skills/inject-context/codebase-map/SKILL.md)
```markdown
---
name: inject-context:codebase-map
description: >
  코드베이스 구조 컨텍스트를 현재 에이전트에 주입합니다.
  코드베이스의 모듈 구조, 의존성, 컨벤션 정보가 필요할 때 사용합니다.
---

# Codebase Map Context Injection

## 절차
1. .graft/knowledge/product_domain.json 파일을 읽음
2. 현재 작업과 관련된 엔티티를 graph_traverse로 추출
   - 시작점: 현재 feature 관련 엔티티
   - 최대 2홉까지 탐색
3. 추출된 정보를 아래 형식으로 압축

## 출력 형식 (최대 3000 토큰)
```
[CTX:CODEBASE_MAP]
modules:
  - name: <module> | files: <count> | pattern: <arch_pattern>
    deps: [<key_dependencies>]
    conventions: [<coding_conventions>]
  ...
relations:
  - <module_a> -> <module_b>: <relation_type>
  ...
[/CTX:CODEBASE_MAP]
```

## 토큰 제어
- 전체 파일 리스트를 나열하지 않음
- 모듈 단위 요약만 제공
- 3000 토큰 초과 시 relevance score 하위 항목부터 제거
- 현재 태스크와 무관한 모듈은 이름만 표시
```

## 3. Edge Transform → Hook Script

### Input (.gft)
```graft
edge Analyzer -> Reviewer {
  transform {
    select: issues where severity >= "medium"
    drop: reasoning_trace
    format: compact
  }
}
```

### Output (.claude/hooks/transform-analyzer-to-reviewer.sh)
```bash
#!/bin/bash
# Auto-generated by Graft Compiler
# Edge: Analyzer -> Reviewer
# Transform: select severity>=medium, drop reasoning_trace, format compact

set -euo pipefail

INPUT_FILE=".graft/session/node_outputs/analyzer.json"
OUTPUT_FILE=".graft/session/node_outputs/analyzer_to_reviewer.json"
TOKEN_LOG=".graft/token_log.txt"

if [ ! -f "$INPUT_FILE" ]; then
  echo "[Graft] ERROR: Analyzer output not found at $INPUT_FILE" >&2
  exit 1
fi

# Transform: select + drop + compact
jq '{
  issues: [.issues[] | select(.severity == "medium" or .severity == "high" or .severity == "critical")],
  risk_score: .risk_score
}' "$INPUT_FILE" > "$OUTPUT_FILE"

# Token accounting
ORIGINAL=$(wc -c < "$INPUT_FILE")
TRANSFORMED=$(wc -c < "$OUTPUT_FILE")
REDUCTION=$(( (ORIGINAL - TRANSFORMED) * 100 / ORIGINAL ))
TIMESTAMP=$(date '+%Y-%m-%d %H:%M:%S')

echo "[$TIMESTAMP] Edge Analyzer->Reviewer | ${ORIGINAL}B → ${TRANSFORMED}B (${REDUCTION}% reduction)" >> "$TOKEN_LOG"
```

### Hook Registration (.claude/settings.json)
```json
{
  "hooks": {
    "PostToolUse": [
      {
        "matcher": "Write(.graft/session/node_outputs/analyzer.json)",
        "command": ".claude/hooks/transform-analyzer-to-reviewer.sh"
      }
    ]
  }
}
```

## 4. Graph Flow → CLAUDE.md Orchestration

### Input (.gft)
```graft
graph CodeReviewPipeline {
  input: PullRequest
  output: ReviewDecision
  budget: 25000 tokens

  flow {
    Analyzer
    -> parallel {
      SecurityReviewer
      PerformanceReviewer
    }
    -> Aggregator
    -> done
  }
  
  shared_context: [ProjectSpec]
}
```

### Output (CLAUDE.md 오케스트레이션 섹션)
```markdown
# Graft Orchestration: CodeReviewPipeline

> 이 프로젝트는 Graft 컴파일러에 의해 생성된 에이전트 팀 오케스트레이션입니다.
> 직접 수정하지 마세요. 수정이 필요하면 .gft 소스를 편집하고 재컴파일하세요.

## Execution Plan

총 토큰 예산: 25,000
공유 컨텍스트: ProjectSpec (모든 에이전트가 접근 가능)

### Phase 1: Analysis [sequential]
- 에이전트: analyzer
- 예상 토큰: input ~5,000 / output ~2,000
- 완료 조건: ===NODE_COMPLETE:analyzer=== 확인
- 결과 저장: .graft/session/node_outputs/analyzer.json

### Phase 2: Review [parallel] 
에이전트 팀 생성:
- 에이전트: security-reviewer (예상: ~4,000 tokens)
- 에이전트: performance-reviewer (예상: ~4,000 tokens)

중요: 각 에이전트는 Analyzer의 **전체 출력이 아닌 변환된 출력**을 수신합니다.
(edge transform에 의해 severity >= medium만 필터링됨)
입력 파일: .graft/session/node_outputs/analyzer_to_*.json

### Phase 3: Aggregation [sequential]
- 에이전트: aggregator
- 입력: Phase 2 모든 에이전트의 출력을 병합
- 예상 토큰: input ~3,000 / output ~1,000

## Token Budget Tracking
각 Phase 완료 후 .graft/token_log.txt 확인.
- 예산 80% 소진 시: 남은 에이전트를 compact 모드로 전환
- 예산 90% 소진 시: 필수 에이전트만 실행, 나머지 skip

## Failure Recovery
- 에이전트 실패: on_failure 정책에 따라 retry/fallback/abort
- 토큰 초과: compact 모드 전환 후 계속 진행
- 전체 실패: .graft/session/에 중간 결과 보존, 수동 복구 가능

## Data Flow Diagram
```
PullRequest
    │
    ▼
[Analyzer] ─── .graft/session/node_outputs/analyzer.json
    │
    ├── transform(select severity>=medium) ──→ [SecurityReviewer]
    │                                              │
    └── transform(select severity>=medium) ──→ [PerformanceReviewer]
                                                   │
                                    merge ◄────────┘
                                      │
                                      ▼
                                [Aggregator]
                                      │
                                      ▼
                              ReviewDecision
```

## 7. CLI Commands

```bash
# 컴파일: .gft → .claude/ 구조 생성
graft compile <source.gft> [--target claude-code] [--output-dir .]

# 실행: 컴파일된 구조를 Claude Code로 실행
graft run <source.gft> --input <input.json>

# 분석만: 토큰 흐름 정적 분석 (실행 없음)
graft analyze <source.gft>

# 검증: 문법 + 타입 + 스코프 체크 (컴파일 없음)
graft check <source.gft>

# 토큰 리포트: 마지막 실행의 토큰 사용 리포트
graft report [--format json|text|chart]

# 초기화: 새 Graft 프로젝트 생성
graft init [--template basic|full]
```
