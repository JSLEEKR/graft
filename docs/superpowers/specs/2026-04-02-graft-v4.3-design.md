# Graft v4.3 Design Spec — Arithmetic Completion & Runtime Polish

## Version Goal

Complete the arithmetic expression system with multiplication/modulo, add essential builtins (`abs`, `round`, `keys`), extract expression evaluator, and close carried exhaustive switch gaps. Mixed feature + quality release.

## Scope

### IN

1. **Multiplication and modulo operators** (`*`, `%`): Complete the arithmetic operator set. Adds `Star` and `Percent` tokens to lexer, `*` and `%` to binary op union, multiplicative precedence level in parser (higher than additive).

2. **New builtin functions** (`abs`, `round`, `keys`):
   - `abs(n)` — absolute value (number → number)
   - `round(n)` — round to nearest integer (number → number)
   - `keys(obj)` — object keys as array (object → array, enables `len(keys(A.output))`)

3. **Expression evaluator extraction**: Extract `evaluateExpr`, `resolveNestedField`, and builtin dispatch from `flow-runner.ts` to `src/runtime/expr-eval.ts`. flow-runner.ts at 386 lines and growing — extraction before it crosses 400.

4. **str() JSON.stringify improvement** (retro-technical finding): `str(someObject)` currently returns `[object Object]`. Change to `JSON.stringify(value)` for objects/arrays.

5. **Remaining exhaustive switches** (carried from v4.1): `applyOne` in transforms.ts, `evaluateExpr` binary op switch.

### OUT

- User-defined functions — builtin-only by design
- Graph call as expression — requires deeper parser changes, v5.0+
- Variable-arity builtins — current fixed arity sufficient
- Lambda/anonymous graphs — v5.0+
- TD-05 through TD-10 (all LOW, permanent carry)

## Process Rules

- R1 (operators + builtins): MEDIUM tier — new tokens, new precedence level, new builtins
- R2 (extraction + str fix + switches): DIRECT tier — refactoring + targeted fixes
- R3 (integration): TEST-ONLY tier — standard integration round
