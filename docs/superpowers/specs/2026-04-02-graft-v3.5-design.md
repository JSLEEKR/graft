# Graft v3.5 Design Specification

**Date**: 2026-04-02
**Version**: 3.5.0
**Theme**: Rename hardening, LSP refinements

## Overview

v3.5 hardens the rename feature shipped in v3.4 by addressing A3-Skeptic's findings (R-PROC-15 backlog items), and adds minor LSP refinements.

## Features

### F-01: Rename Correctness Fixes (A3 backlog)

- Extract `isInComment()` and `isInString()` from completions.ts to utils.ts (shared)
- Filter `collectRenameLocations` results to skip comment/string/import-path positions
- CRLF normalization: strip `\r` before processing
- newName validation: identifier regex + keyword blacklist
- Import path exclusion: don't match names inside `from "..."` strings

### F-02: Cross-file Conflict Detection + Handler Extraction

- Before applying cross-file rename, check new name doesn't conflict in importing files
- Extract rename handler logic from server.ts to a pure function in features/rename.ts

### F-03: FlowNode Location + Symbol Children

- Add location data to FlowNode 'node' kind in parser (enables outline navigation)
- Add parallel/foreach children to document symbols

## Non-Goals

- Memory importability, additional code actions, async I/O, source maps
