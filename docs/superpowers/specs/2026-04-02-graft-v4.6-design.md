# Graft v4.6 Design Spec — Logical Operators & Expression Polish

## Overview

v4.6 adds logical operators (`&&`, `||`) to complete boolean logic in expressions, and polishes the expression system with unary `not` support and type mismatch warnings for conditional branches.

## Feature 1: Logical Operators

### Goal
Enable `&&` (logical AND) and `||` (logical OR) in expressions for combining boolean conditions.

### Syntax
```graft
graph G(input: In, output: Out, budget: 10k) {
  A -> let valid = A.score > 50 && A.status == "ok"
     -> let fallback = A.score < 10 || A.retries > 3
     -> let result = if valid then "proceed" else "halt"
     -> done
}
```

### Design

#### Lexer/Tokens
- Add `AmpAmp` token (`&&`)
- Add `PipePipe` token (`||`)

#### AST
Extend binary op union: add `'&&' | '||'`

#### Parser Precedence
Insert two new levels between assignment and comparison:
```
parseExpr → parseLogicalOr (||) → parseLogicalAnd (&&) → parseComparison → parseAdditive → parseMultiplicative → parseUnary → parsePrimary
```
- `||` is lower precedence than `&&` (standard)
- Both are lower precedence than comparison operators

#### Runtime (expr-eval.ts)
- `&&`: short-circuit — if left is falsy, return left; otherwise return right
- `||`: short-circuit — if left is truthy, return left; otherwise return right

#### Type Checker
- `&&` and `||` result type: `boolean` when both operands are boolean, otherwise `unknown`
- Warn if non-boolean operands used with logical operators

### Constraints
- Short-circuit evaluation is required (not just for optimization — prevents errors in chained checks)
- No bitwise operators — `&` and `|` are not supported

## Feature 2: Conditional Branch Type Mismatch Warning

### Goal
Warn when `if-then-else` branches have different types (currently silently infers `unknown`).

### Design
In `checkExprTypeErrors` for conditional expressions:
- If consequent and alternate types are both known but different, emit a warning
- Error code: `TYPE_CONDITIONAL_MISMATCH`
- Severity: `warning` (not error — the code still works, just loses type precision)

### Example
```graft
// Warning: conditional branches have different types: 'string' and 'number'
let x = if A.score > 50 then "high" else 42
```

## Feature 3: Expression System Regression Hardening

### Goal
Comprehensive integration tests for the full expression system covering all 9 Expr kinds, all operators, and cross-feature interactions.

## Scope Boundaries

**IN**: logical operators (&&, ||), conditional type mismatch warning, regression hardening
**OUT**: bitwise operators, pattern matching, user-defined functions, ternary syntax (`? :`)
