# Graft v3.6 Design Specification

**Date**: 2026-04-02
**Version**: 3.6.0
**Theme**: LSP find-all-references, keyword unification, polish

## Overview

v3.6 adds find-all-references (the last major LSP feature for a complete editing experience), unifies the keyword system, and polishes rename and symbol ranges. This version intentionally includes one MEDIUM round to generate adversarial analysis (two consecutive versions without A3 is the monitoring threshold from v3.5 retro).

## Features

### F-01: Find All References (LSP textDocument/references)

- Implement `textDocument/references` handler for contexts, nodes, memories, and graphs
- Reuse `collectRenameLocations` infrastructure (word-boundary regex + comment/string/import-path filtering)
- Cross-file reference finding via workspace export cache (same as rename)
- Include declaration site when `context.includeDeclaration` is true
- Return `Location[]` (URI + range)

### F-02: Keyword Unification (TD-01 + TD-02)

- Derive `GRAFT_KEYWORDS` from lexer `KEYWORDS` object instead of maintaining a separate list
- Exclude type keywords (`String`, `Int`, `Float`, `Bool`, etc.) that are valid as contextual identifiers
- Replace regex-based cross-file conflict detection with parse-based check using ProgramIndex

### F-03: Symbol Range + Rename Polish

- Fix document symbol `range` to span full declaration (not just name) — use next declaration start or EOF as end
- Add rename guard for field name collision (warn when renamed name matches a field in a reads/writes context)

## Non-Goals

- Memory importability, async I/O, source maps, AST-based reference tracking (full rewrite)
- Runtime changes (foreach failure, multi-hop conditional routing, budget enforcement)
