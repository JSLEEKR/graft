# Graft v3.7 Design Specification

**Date**: 2026-04-02
**Version**: 3.7.0
**Theme**: Runtime hardening, server.ts cleanup

## Overview

v3.7 pivots from LSP investment (5 consecutive versions, v3.2-v3.6) to runtime hardening. It addresses three long-deferred runtime gaps and extracts server.ts orchestration to stay under the 400-line threshold.

## Features

### F-01: Server.ts Orchestration Extraction + Reference Position Fix

- Extract duplicated workspace scanning orchestration from server.ts handlers (rename, references, code-actions) into a shared helper
- Fix findDeclNamePosition in references.ts to use SourceLocation.length instead of hardcoded keyword lengths

### F-02: Foreach Source Failure Handling

- Define behavior when the source node for a foreach fails (currently undefined)
- If source node execution fails, skip the foreach body and propagate the failure according to the source node's on_failure strategy
- The foreach itself does not have its own failure strategy — it inherits from the source node

### F-03: Multi-hop Conditional Edge Routing

- Conditional edges currently evaluate one hop only
- Enable chained conditional routing: if a conditional edge target is itself a conditional edge source, evaluate the chain
- Limit chain depth to prevent infinite loops (max 10 hops)
- Update token estimator to account for multi-hop conditional paths

## Non-Goals

- Memory importability, async I/O, source maps, AST-based reference tracking
- New LSP features (the LSP is mature at 8 features)
- New code actions beyond auto-import
