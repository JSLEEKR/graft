# Graft v4.2 Implementation Plan

## Overview

Expression functions + runtime consistency. 4 rounds, ~14 agent calls estimated.

## Rounds

### R1: Expression Functions — Lexer + AST + Parser + Evaluator (MEDIUM, A2+A3)

**Scope**: New `call` Expr kind, parser changes, evaluateExpr function dispatch, scope checker validation, type checker arity/type checks.

**Files to modify**:
- `src/parser/ast.ts` — Add ExprCall to Expr union
- `src/lexer/tokens.ts` — No changes needed (uses existing Identifier + LParen)
- `src/parser/parser.ts` — parsePrimary: detect builtin function call (Identifier + LParen where name is in BUILTIN_FUNCTIONS)
- `src/runtime/flow-runner.ts` — evaluateExpr: handle 'call' kind with built-in dispatch
- `src/analyzer/scope.ts` — checkExprSources: handle 'call' kind (validate function name, recurse into args)
- `src/analyzer/types.ts` — checkExprType: handle 'call' kind (validate arity, arg types, return type)
- `src/analyzer/graph-checker.ts` — checkExprSources: update if expr traversal needed
- `src/errors/diagnostics.ts` — New error codes: SCOPE_UNKNOWN_FUNCTION, TYPE_FUNC_ARITY, TYPE_FUNC_ARG

**New file**:
- `src/runtime/builtins.ts` — BUILTIN_FUNCTIONS registry + evalBuiltin dispatcher

**Test file**: `tests/v42-r1.test.ts`

**Test targets** (~20 tests):
- Parse: `len(x)`, `max(a, b)`, `min(a, b)`, `str(v)`, nested `len(Sub.output.items)`
- Evaluate: len on array, len on string, max/min numeric, str conversion
- Scope: unknown function name → SCOPE_UNKNOWN_FUNCTION
- Type: wrong arity → TYPE_FUNC_ARITY, non-numeric args for max/min → TYPE_FUNC_ARG
- Integration: `let count = len(Analyzer.issues)` in flow

**Complexity**: MEDIUM — new Expr kind touches parser + evaluator + scope + type checker. A2+A3 debate for design decisions (function call vs method call syntax, builtin registry pattern).

### R2: Graph Call Return Values + Equality + Exhaustive Switches (DIRECT)

**Scope**: Graph call output capture, equality semantics unification, remaining exhaustive switch defaults.

**Files to modify**:

- `src/runtime/transforms.ts` — evalCondition: `===`/`!==` → `==`/`!=`; applyOne: add `never` default
- `src/runtime/flow-runner.ts` — evaluateExpr binary switch: add `never` default (if not covered by R1)

**Test file**: `tests/v42-r2.test.ts`

**Test targets** (~12 tests):
- Graph call return: `let x = Sub().field` captures output
- Graph call return: nested graph call output accessible
- Equality: loose equality in transforms (string "200" == number 200)
- Equality: strict inequality still works for !=
- Exhaustive: new transform type causes compile error (type-level test)

**Complexity**: DIRECT — targeted fixes, clear implementation path.
