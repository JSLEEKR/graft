## Round Details

### R1: Logical Operators (DIRECT)

**Files to modify**:
- `src/lexer/tokens.ts`: Add `AmpAmp`, `PipePipe` token types
- `src/lexer/lexer.ts`: Lex `&&` and `||` (two-char lookahead)
- `src/parser/ast.ts`: Extend binary op union with `'&&' | '||'`
- `src/parser/parser.ts`: Add `parseLogicalOr` and `parseLogicalAnd` precedence levels
- `src/runtime/expr-eval.ts`: Short-circuit evaluation for `&&` and `||`
- `src/analyzer/types.ts`: `&&`/`||` return boolean, warn on non-boolean operands
- `editors/vscode/syntaxes/graft.tmGrammar.json`: Add `&&` and `||` to operators pattern

**Test file**: `tests/v46-r1.test.ts`
- Parse: `&&` and `||` compile in expressions
- Precedence: `a || b && c` parses as `a || (b && c)`
- Precedence: `a && b > c` parses as `a && (b > c)`
- Evaluate: short-circuit true/false cases
- Type: boolean inference, non-boolean warning

### R2: Conditional Type Mismatch Warning (DIRECT)

**Files to modify**:
- `src/analyzer/types.ts`: Add warning in `checkExprTypeErrors` for conditional with mismatched branch types
- `src/errors/diagnostics.ts`: Add `TYPE_CONDITIONAL_MISMATCH` error code if not exists

**Test file**: `tests/v46-r2.test.ts`
- Same-type branches: no warning
- Different-type branches: warning emitted
- Unknown-type branches: no warning (can't determine mismatch)
- Nested conditional: warning on inner mismatch

### R3: Integration + Regression Hardening (TEST-ONLY)

**Test file**: `tests/v46-r3.test.ts`
- Cross-feature: logical operators with conditional expressions
- Cross-feature: `&&`/`||` with comparison + arithmetic
- Regression: all 9 Expr kinds still work
- Scale: complex expressions with all operator types
- TextMate grammar: `&&` and `||` in operators

## Dependencies
- R1 must complete before R2 (logical ops needed for type checker test combos)
- R3 depends on R1 + R2
